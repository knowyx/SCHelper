Проект SCHelper — это удобное графическое приложение, предназначенное для автоматизации повседневных задач школьников. Основная цель программы — избавить учащихся от рутины, связанной с организацией расписания, подготовкой к экзаменам и другими учебными делами. Интерфейс интуитивно понятен, что делает работу с приложением комфортной даже для начинающих пользователей.
Описание реализации:  
Приложение реализовано на языке Python с использованием библиотеки PyQt для создания графического интерфейса. Архитектура проекта разделена на отдельные модули, каждый из которых отвечает за работу определённого окна приложения.  

Основные компоненты программы:  
● mainUI.py — главное окно приложения  
● timetable.py — модуль, отвечающий за отображение и редактирование расписания  
● examUI.py — окно подготовки к экзаменам   
● crontabUI.py — окно с планировщиком задач
● aboutUI.py — раздел «О программе»  

Каждое окно реализовано в отдельном классе, что обеспечивает удобство поддержки и расширяемость проекта. Приложение построено по принципу модульности, что позволяет легко добавлять новые функции и улучшать существующие.

Используемые технологии и зависимости:  
● Язык программирования: Python  
● Основная библиотека: PyQt (для графического интерфейса)  
● Форматы дистрибуции: архив .tar.gz  

Запуск проекта:  
1. Распаковать архив .tar.gz
2. Установить зависимости командой: pip install -r requirements.txt
3. Запустить файл: main.py или исполняемый файл нужной системы

Для сборки используется команда:
pyinstaller --icon=icon.ico --noconsole -F main.py
