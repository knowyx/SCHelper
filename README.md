Для запуска с OS Linux:
  1.Скачайте Asset из вкладки Releases
  2.Распакуйте его
  3.Задайте файлу main.py атрибут исполняемого файла
  4.Нажмите ПКМ по файлу main.py и выберете "Запустить с помощью"
  5.Введите в путь к файлу usr/bin/python3.XX (Вместо XX должна быть версия python, установленная на вашем ПК)


Для работы необходима библиотека PyQt5
