<p class="has-line-data" data-line-start="0" data-line-end="6">Для запуска с OS Linux:<br>
1.Скачайте Asset из вкладки Releases<br>
2.Распакуйте его<br>
3.Задайте файлу main.py атрибут исполняемого файла<br>
4.Нажмите ПКМ по файлу main.py и выберете “Запустить с помощью”<br>
5.Введите в путь к файлу usr/bin/python3.XX (Вместо XX должна быть версия python, установленная на вашем ПК)</p>
<p class="has-line-data" data-line-start="8" data-line-end="9">Для работы необходима библиотека PyQt5</p>
